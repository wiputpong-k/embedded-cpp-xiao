    วิธีเรียน

    เรียนวันละบทตามลำดับ รวม 25 บท ประมาณ 12 ชั่วโมง แต่ละบทมี เป้าหมาย → แนวคิด + diagram → hands-on → คำถามเช็ก ทุกบทต่อยอดจากบทก่อน โค้ดในบท 07, 10 และ 13–14 จะถูกนำไป test และ build ใน CI ช่วงท้าย

    บท 00–14 ใช้ Arduino IDE 2 + core Seeed nRF52 (non-mbed) เพราะเร็วที่สุดในการเห็นผล หลักภาษาเหมือนกันทุก framework เมื่อจบแล้วย้ายไป nRF Connect SDK / Zephyr ได้ทันที

    ความคืบหน้าและบทล่าสุดที่เปิดจะถูกจำไว้ในเบราว์เซอร์นี้ ใช้ร่วมกันทั้งภาษาไทยและอังกฤษ

    อุปกรณ์

    • 1 Seeed XIAO nRF52840 (Sense) + สาย USB-C แบบ data
    • 1 breadboard + สาย jumper
    • 1 LED 5 mm + R 1 kΩ
    • 1 ปุ่มกด tactile
    • 1 potentiometer 10 kΩ
    • — Arduino IDE 2, Git, บัญชี GitHub (ติดตั้งในบทที่ใช้)
