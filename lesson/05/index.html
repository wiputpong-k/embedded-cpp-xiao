เป้าหมาย ย้าย class Led ไปไว้ในไฟล์ src/Led.h เพื่อใช้ซ้ำในบทหลัง ๆ

C

แยก .h (ประกาศ) กับ .c (ตัวฟังก์ชัน) และกัน include ซ้ำด้วย #ifndef guard

C++

class ที่เขียนตัวฟังก์ชันไว้ในตัว class อยู่ใน .h ไฟล์เดียวได้ เพราะฟังก์ชันแบบนี้เป็น inline โดยอัตโนมัติ กัน include ซ้ำด้วย #pragma once บรรทัดเดียว

เมื่อโปรเจกต์ใหญ่ขึ้น การเก็บทุกอย่างไว้ในไฟล์ .ino เดียวจะอ่านยาก และนำไปใช้ซ้ำไม่ได้ Arduino จะ compile ทุกไฟล์ในโฟลเดอร์ src/ ที่อยู่ในโฟลเดอร์ sketch ให้อัตโนมัติ คอร์สนี้จึงเก็บ class ที่ใช้ซ้ำไว้ใน src/ ตั้งแต่บทนี้ไปจนถึงบท 13

Arduino IDE 2 แสดงเป็นแท็บเฉพาะไฟล์ที่อยู่ชั้นบนสุดของโฟลเดอร์ sketch ไฟล์ใน src/ จะไม่ขึ้นเป็นแท็บ ต้องแก้ด้วยโปรแกรมอื่น เช่น VS Code หรือ Notepad แต่ IDE ยัง compile ไฟล์เหล่านี้ตามปกติ

Hands-on

  1. เปิด sketch led_class จากบทที่แล้ว (File → Open… หรือ File → Sketchbook)
  2. กด Sketch → Show Sketch Folder จะเปิดโฟลเดอร์ของ sketch ใน File Explorer
  3. ถ้ายังมองไม่เห็นนามสกุลไฟล์ ให้เปิดใน File Explorer: View → Show → File name extensions
  4. สร้างโฟลเดอร์ใหม่ชื่อ src แล้วเข้าไปในโฟลเดอร์นั้น คลิกขวา New → Text Document เปลี่ยนชื่อเป็น Led.h (ต้องลบ .txt ออกด้วย) ถ้า Windows ถามเรื่องเปลี่ยนนามสกุล ให้กด Yes
  5. คลิกขวาที่ Led.h แล้วเปิดด้วย VS Code หรือ Notepad คัดลอกโค้ด src/Led.h ข้างล่างไปวาง แล้วบันทึก
  6. กลับมาที่ Arduino IDE แทนที่โค้ดใน led_class.ino ทั้งหมดด้วยโค้ดชุดที่สองข้างล่าง แล้วกด Upload ผลต้องเหมือนบทที่แล้วทุกอย่าง
src/Led.h
#pragma once
#include <Arduino.h>

class Led {
public:
  Led(uint8_t pin, bool activeLow) : pin_(pin), activeLow_(activeLow) {}

  void begin() { pinMode(pin_, OUTPUT); off(); }
  void on()     { write(true); }
  void off()    { write(false); }
  void toggle() { write(!isOn_); }
  bool isOn() const { return isOn_; }   // const method: ไม่แก้ state

private:
  void write(bool on) {
    isOn_ = on;
    digitalWrite(pin_, (on != activeLow_) ? HIGH : LOW);
  }
  uint8_t pin_;
  bool activeLow_;
  bool isOn_ = false;
};
led_class.ino
#include <Adafruit_TinyUSB.h>   // เปิด USB และ Serial (core นี้ต้องมี)
#include "src/Led.h"

Led red(LED_RED, true);   // บนบอร์ด: active-LOW
Led ext(D2, false);       // ภายนอก: active-HIGH

void setup() {
  red.begin();
  ext.begin();
}

void loop() {
  red.toggle();
  ext.toggle();
  delay(300);
}

#include "src/Led.h" ใช้เครื่องหมายคำพูด แปลว่าให้หาไฟล์จากโฟลเดอร์ของ sketch ก่อน ส่วน #include <Arduino.h> ใช้วงเล็บมุม แปลว่าหาจาก library และ core ที่ติดตั้งไว้ ไฟล์ Led.h ต้อง include Arduino.h เอง เพราะ IDE เติมให้เฉพาะไฟล์ .ino

เช็กความเข้าใจ

ถ้าลบ #pragma once ออก แล้ว include Led.h จาก 2 ไฟล์ที่ include ต่อกัน จะเกิดอะไรขึ้น?

compiler เห็น class Led ถูกประกาศ 2 ครั้งใน translation unit เดียว แล้ว error ว่า redefinition #pragma once (หรือ #ifndef guard) ทำให้ไฟล์ถูกอ่านแค่ครั้งเดียว

ทำไมเขียนตัวฟังก์ชันไว้ใน Led.h แล้ว include จากหลายไฟล์ .cpp ได้โดยไม่ error multiple definition?

ฟังก์ชันที่เขียนไว้ใน class body เป็น inline โดยอัตโนมัติ linker จึงยอมให้มีหลายสำเนาและเลือกใช้ตัวเดียว ถ้าเขียนฟังก์ชันธรรมดานอก class ไว้ใน .h ต้องใส่ inline เอง

มุมงานจริง

บั๊ก "static initialization order fiasco" เจอได้จริงในโปรเจกต์หลายไฟล์: ลำดับการสร้าง global object ข้ามไฟล์ไม่ถูกกำหนด object หนึ่งอาจเรียกใช้อีกตัวที่ยังไม่ถูกสร้าง ทางแก้คือ begin() หรือ function-local static
