class: encapsulation และ constructor

30 นาที · ฮาร์ดแวร์: LED + R 1 kΩ

เป้าหมาย ต่อ LED ภายนอก และเขียน class Led ที่ซ่อนเรื่อง active-LOW ไว้ข้างใน

C

struct เก็บข้อมูล + ฟังก์ชัน led_on(&led) แยกกัน ใครก็แก้ field ได้

C++

ข้อมูล (private) และพฤติกรรม (public) อยู่ด้วยกัน คอมไพล์แล้วได้โค้ดขนาดใกล้เคียงกัน เพราะ this ก็คือ pointer ที่ส่งเข้าไปแบบซ่อน

  • class / object class คือแบบพิมพ์ (เหมือน struct ที่มีฟังก์ชันอยู่ด้วย) object คือตัวจริงที่สร้างจากแบบนั้น เช่น red และ ext
  • encapsulation ซ่อนข้อมูลไว้ใน private: ให้ภายนอกใช้ได้แค่ฟังก์ชันใน public: จึงไม่มีใครแก้ค่าข้างในผิด ๆ ได้
  • constructor ฟังก์ชันชื่อเดียวกับ class ไม่มีชนิด return ทำงานอัตโนมัติตอนสร้าง object ใช้ตั้งค่าเริ่มต้น ส่วน : pin_(pin) เรียกว่า member initializer list คือการกำหนดค่า member ตอนสร้าง
  • this pointer ไปยัง object ที่กำลังถูกเรียก compiler ส่งให้ทุกฟังก์ชันใน class แบบซ่อน เทียบได้กับ &led ใน led_on(&led) ของ C

ต่อวงจร

breadboard คือแผงเสียบสายที่ไม่ต้องบัดกรี รู 5 รูที่เรียงอยู่ในแถวเดียวกัน (แนวตั้งฉากกับร่องกลาง) ต่อถึงกันอยู่ข้างใน ส่วนแถวยาวตามขอบที่มีเส้นสีแดงและน้ำเงิน ใช้เป็นรางไฟและราง GND

  1. ถอดสาย USB ออกก่อนต่อวงจรทุกครั้ง
  2. เสียบบอร์ด XIAO คร่อมร่องกลางของ breadboard ให้ขาแต่ละข้างอยู่คนละฝั่ง (ถ้าบอร์ดยังไม่ได้บัดกรีขา header ต้องบัดกรีก่อน)
  3. ดูขั้วของ LED: ขายาวคือขั้วบวก (anode) ขาสั้นคือขั้วลบ (cathode) และขอบหัว LED ด้านที่แบนคือฝั่งขั้วลบ
  4. ต่อสาย jumper จากขา D2 ไปที่ขาหนึ่งของ R 1 kΩ (ตัวต้านทานไม่มีขั้ว กลับด้านได้)
  5. ต่ออีกขาของ R เข้ากับขายาวของ LED
  6. ต่อขาสั้นของ LED ไปที่ขา GND ของบอร์ด

ถ้า LED ไม่ติด ให้ลองกลับด้าน LED ก่อน เพราะเป็นสาเหตุที่เจอบ่อยที่สุด R 1 kΩ มีไว้จำกัดกระแส ห้ามต่อ LED ตรงกับขาโดยไม่มี R

Hands-on

sketch นี้พิสูจน์ encapsulation: LED 2 ดวงที่ต่อวงจรต่างกัน (active-LOW และ active-HIGH) ถูกสั่งด้วยคำสั่งเดียวกัน

  1. เสียบสาย USB กลับ แล้วกด File → New Sketch
  2. คัดลอกโค้ดข้างล่างไปวางแทนโค้ดเดิม แล้วกด File → Save As… ตั้งชื่อ led_class
  3. กด Upload แล้วดูผล: LED แดงบนบอร์ดและ LED ภายนอกกระพริบพร้อมกันทุก 0.3 วินาที
led_class.ino
#include <Adafruit_TinyUSB.h>   // เปิด USB และ Serial (core นี้ต้องมี)
class Led {
public:
  Led(uint8_t pin, bool activeLow) : pin_(pin), activeLow_(activeLow) {}

  void begin() { pinMode(pin_, OUTPUT); off(); }
  void on()     { write(true); }
  void off()    { write(false); }
  void toggle() { write(!isOn_); }
  bool isOn() const { return isOn_; }   // const method: ไม่แก้ state

private:
  void write(bool on) {
    isOn_ = on;
    digitalWrite(pin_, (on != activeLow_) ? HIGH : LOW);
  }
  uint8_t pin_;
  bool activeLow_;
  bool isOn_ = false;
};

Led red(LED_RED, true);   // บนบอร์ด: active-LOW
Led ext(D2, false);       // ภายนอก: active-HIGH

void setup() {
  red.begin();
  ext.begin();
}

void loop() {
  red.toggle();
  ext.toggle();
  delay(300);
}

สังเกตว่าทั้งสองดวงติดพร้อมกัน แม้ LED บนบอร์ดเป็น active-LOW และ LED ภายนอกเป็น active-HIGH เพราะ class จัดการเรื่องนี้ไว้ใน write() คนที่เรียกใช้แค่สั่ง on() หรือ toggle() ไม่ต้องรู้ว่าต่อวงจรแบบไหน

ทำไมมี begin() แยก ไม่เรียก pinMode ใน constructor? เพราะ constructor ของ object global ถูกเรียกโดย startup code ก่อน main() (ดูแผนภาพบท 01) จึงทำงานก่อน init() ฮาร์ดแวร์อาจยังไม่พร้อม เป็น pattern มาตรฐานของ embedded C++

เช็กความเข้าใจ

member initializer list (: pin_(pin)) ดีกว่ากำหนดค่าใน body อย่างไร?

สร้าง member ด้วยค่าที่ถูกต้องตั้งแต่แรก ไม่ต้องสร้างด้วยค่าเริ่มต้นแล้วค่อยกำหนดค่าใหม่ และจำเป็นสำหรับ member ที่เป็น const หรือ reference

object Led ใช้ RAM กี่ byte โดยประมาณ?

ราว 3–4 byte (pin_, activeLow_, isOn_ และอาจมี padding คือ byte ว่างที่ compiler เติมให้ข้อมูลเรียงตรงตำแหน่ง) ฟังก์ชันไม่กิน RAM ต่อ object เพราะอยู่ใน flash ใช้ร่วมกัน
