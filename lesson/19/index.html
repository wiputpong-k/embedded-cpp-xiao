เป้าหมาย ติดตั้ง g++ แล้วรัน test ของ Debouncer และ RingBuffer บน PC ได้ในไม่กี่วินาที โดยไม่ต้องเสียบบอร์ด

Debouncer และ RingBuffer ไม่เรียก Arduino API เลย Debouncer รับเวลาเป็นพารามิเตอร์ (nowMs) แทนการเรียก millis() เอง นี่คือเทคนิค dependency injection แบบง่ายที่สุด ทำให้ compile ด้วย g++ บน PC ได้ และ test ควบคุมเวลาได้ทุกมิลลิวินาที

ขั้นที่ 1: ติดตั้ง g++

Windows ไม่มี compiler C++ มาให้ วิธีที่แนะนำคือติดตั้งผ่าน MSYS2

  1. เปิดหน้า msys2.org ดาวน์โหลดตัวติดตั้ง (msys2-x86_64-….exe) แล้วติดตั้งตามค่าเริ่มต้น จะได้โฟลเดอร์ C:\msys64
  2. เปิดโปรแกรม MSYS2 UCRT64 จาก Start menu แล้วรันคำสั่งแรกข้างล่าง ถ้าถามให้ยืนยัน ให้กด Enter หรือพิมพ์ Y
  3. ให้ Git Bash มองเห็น g++: กดปุ่ม Windows พิมพ์ Edit environment variables for your account เลือก Path → Edit → New ใส่ C:\msys64\ucrt64\bin แล้วกด OK ทุกหน้าต่าง
  4. ปิด Git Bash แล้วเปิดใหม่ รัน g++ --version ต้องเห็นเลขเวอร์ชัน

macOS: รัน xcode-select --install จะได้ compiler ที่เรียกด้วยชื่อ g++ ได้ Linux (Ubuntu): รัน sudo apt install g++

MSYS2 UCRT64
pacman -S mingw-w64-ucrt-x86_64-gcc

ขั้นที่ 2: เพิ่มไฟล์ test แล้วรัน

  1. ใน Git Bash เข้าไปที่ repo แล้วสร้างโฟลเดอร์ test (คำสั่ง 2 บรรทัดแรกข้างล่าง)
  2. รัน notepad test/test_main.cpp (หรือ code) วางโค้ด test/test_main.cpp ข้างล่าง แล้วบันทึก
  3. รันคำสั่ง g++ แล้วรัน ./test_runner ต้องเห็น ALL TESTS PASSED
  4. commit ไฟล์ test เข้า repo

-Ifirmware/src บอก g++ ให้หาไฟล์ header ในโฟลเดอร์นั้น test จึง include Debouncer.h และ RingBuffer.h ตัวเดียวกับที่บอร์ดใช้ ส่วน -Wall -Wextra -Werror เปิด warning ทั้งหมดและนับ warning เป็น error

Git Bash
cd ~/xiao-embedded-cpp
mkdir test
g++ -std=c++17 -Wall -Wextra -Werror -Ifirmware/src test/test_main.cpp -o test_runner
./test_runner
# ALL TESTS PASSED
git add test/
git commit -m "test: add host unit tests"
test/test_main.cpp
#include <cstdio>
#include <cstdlib>
#include "RingBuffer.h"
#include "Debouncer.h"

static int failures = 0;
#define CHECK(cond)                                                    \
  do {                                                                 \
    if (!(cond)) {                                                     \
      std::printf("FAIL %s:%d  %s\n", __FILE__, __LINE__, #cond);      \
      ++failures;                                                      \
    }                                                                  \
  } while (0)

static void test_ringbuffer() {
  xiao::RingBuffer<int, 3> rb;
  CHECK(rb.size() == 0);
  CHECK(rb.push(1) && rb.push(2) && rb.push(3));
  CHECK(!rb.push(4));          // เต็มแล้ว
  int v = 0;
  CHECK(rb.pop(v) && v == 1);  // FIFO: ออกตัวแรกก่อน
  rb.pushOverwrite(4);
  rb.pushOverwrite(5);         // เต็ม → ทิ้ง 2
  CHECK(rb.at(0) == 3 && rb.at(2) == 5);
  CHECK(average(rb) == 4.0f);
}

static void test_debouncer() {
  using E = Debouncer::Event;
  Debouncer d(20);
  CHECK(d.update(true, 0) == E::None);   // เริ่มกด
  CHECK(d.update(false, 5) == E::None);  // เด้ง
  CHECK(d.update(true, 8) == E::None);   // เด้ง
  CHECK(d.update(true, 20) == E::None);  // นิ่งมาแค่ 12 ms
  CHECK(d.update(true, 28) == E::Pressed);
  CHECK(d.isPressed());
  CHECK(d.update(true, 40) == E::None);  // กดค้าง ไม่ยิงซ้ำ
}

int main() {
  test_ringbuffer();
  test_debouncer();
  if (failures == 0) std::puts("ALL TESTS PASSED");
  return failures == 0 ? EXIT_SUCCESS : EXIT_FAILURE;
}

เช็กความเข้าใจ

ทำไม exit code สำคัญ?

CI ตัดสินผ่าน/ไม่ผ่านจาก exit code ของคำสั่ง 0 = ผ่าน อย่างอื่น = fail และหยุด pipeline test_main.cpp จึงคืน EXIT_FAILURE เมื่อมี CHECK ที่ไม่ผ่าน

ทำไม test บน PC ไม่ต้องใช้บอร์ด แต่ยังเชื่อถือได้?

เพราะ test compile ไฟล์ header เดียวกับ firmware จริง ทดสอบ logic ล้วน ๆ ส่วนที่ขึ้นกับฮาร์ดแวร์ (การอ่านขา, timing จริง) ยังต้อง test บนบอร์ดแยกต่างหาก
