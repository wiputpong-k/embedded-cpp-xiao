Mini project 1: cooperative scheduler

30 นาที · ฮาร์ดแวร์: LED + ปุ่ม + Pot

ในบทนี้
  1. เตรียมวงจรและโปรเจกต์
  2. ทดสอบ
  3. เช็กความเข้าใจ

เป้าหมาย รวม LED, ปุ่ม และ pot เป็น firmware เดียวที่ไม่มี delay() เลย โครงสร้างแบบนี้ใช้จริงก่อนจะขึ้น RTOS

firmware จริงต้องทำหลายอย่างพร้อมกัน เช่น กระพริบ LED, อ่านปุ่ม และอ่านเซนเซอร์ ถ้าใช้ delay() งานหนึ่งจะบล็อกงานอื่นทั้งหมด วิธีแก้ที่ง่ายที่สุดคือ cooperative scheduler: แบ่งงานเป็น task สั้น ๆ แต่ละ task มีรอบการทำงานของตัวเอง แล้วให้ loop() คอยเช็กว่า task ไหนถึงเวลาแล้วบ้าง

เตรียมวงจรและโปรเจกต์

  1. ต่อวงจรให้ครบ 3 อย่างบน breadboard เดียวกัน: LED + R ที่ D2 (บท 04), pot ที่ A0 (บท 06) และปุ่มที่ D1 (บท 07)
  2. สร้าง sketch ใหม่ แล้วกด File → Save As… ตั้งชื่อ firmware จะได้โฟลเดอร์ firmware/ ที่มีไฟล์ firmware.ino (Arduino บังคับให้ชื่อโฟลเดอร์กับชื่อไฟล์ .ino ตรงกัน)
  3. สร้างโฟลเดอร์ src ในโฟลเดอร์ firmware/ แล้วคัดลอก 3 ไฟล์จากบทก่อนมาไว้: Led.h (บท 05), Debouncer.h (บท 07) และ RingBuffer.h (บท 10)
  4. วางโค้ดข้างล่างใน firmware.ino แล้วกด Upload
firmware/firmware.ino
#include "src/Led.h"
#include "src/Debouncer.h"
#include "src/RingBuffer.h"

#if __has_include("src/version.h")
#include "src/version.h"          // CI สร้างไฟล์นี้ (บท 23)
#else
#define FW_VERSION "dev"
#endif

constexpr uint8_t kButtonPin = D1;
constexpr uint8_t kPotPin    = A0;

Led status(LED_GREEN, true);
Led ext(D2, false);
Debouncer button;
RingBuffer<uint16_t, 16> samples;
bool paused = false;

struct Task {
  uint32_t periodMs;
  uint32_t lastRunMs;
  void (*run)();
};

void blinkTask() { if (!paused) status.toggle(); }

void buttonTask() {
  bool pressed = digitalRead(kButtonPin) == LOW;
  if (button.update(pressed, millis()) == Debouncer::Event::Pressed) {
    paused = !paused;
    ext.toggle();
  }
}

void sensorTask() { samples.pushOverwrite(analogRead(kPotPin)); }

void reportTask() {
  Serial.print("avg:");     Serial.print(average(samples));
  Serial.print(" paused:"); Serial.println(paused ? 1 : 0);
}

Task tasks[] = {
  {500, 0, blinkTask},
  {5,   0, buttonTask},
  {20,  0, sensorTask},
  {200, 0, reportTask},
};

void setup() {
  Serial.begin(115200);
  pinMode(kButtonPin, INPUT_PULLUP);
  status.begin();
  ext.begin();
  Serial.print("fw "); Serial.println(FW_VERSION);
}

void loop() {
  uint32_t now = millis();
  for (Task& t : tasks) {
    if (now - t.lastRunMs >= t.periodMs) {
      t.lastRunMs = now;
      t.run();
    }
  }
}

ทดสอบ

  1. LED เขียวบนบอร์ดต้องกระพริบทุก 0.5 วินาที
  2. กดปุ่ม: LED เขียวหยุดกระพริบ และ LED ภายนอกติด กดอีกครั้งเพื่อกลับเป็นเหมือนเดิม
  3. เปิด Tools → Serial Plotter (ตั้ง 115200 baud) แล้วหมุน pot เส้น avg ต้องขึ้นลงตาม

ทุกอย่างทำงานพร้อมกันโดยไม่มี delay() สักบรรทัด ลองแก้ตัวเลขใน tasks[] เช่นเปลี่ยน blinkTask เป็น 100 แล้ว Upload ใหม่ดูผล

เช็กความเข้าใจ

ถ้า reportTask ใช้เวลา 30 ms จะเกิดอะไรกับ buttonTask?

buttonTask ถูกเลื่อนไปจน reportTask จบ เพราะเป็น cooperative (ไม่มี preemption) ทุก task ต้องสั้น ถ้าทำไม่ได้คือสัญญาณว่าถึงเวลาใช้ RTOS

ทำไม Task ใช้ function pointer ไม่ใช้ std::function?

function pointer ขนาด 4 byte ไม่จอง heap และคาดเดาได้ std::function อาจจอง heap เมื่อ capture ข้อมูล
