GitHub: สร้าง repo และ push

30 นาที · ฮาร์ดแวร์: คอมพิวเตอร์

ในบทนี้
  1. ขั้นที่ 1: สมัครบัญชี GitHub
  2. ขั้นที่ 2: ติดตั้ง GitHub CLI
  3. ขั้นที่ 3: login ครั้งเดียว
  4. ขั้นที่ 4: สร้าง repo บน GitHub แล้ว push
  5. เช็กความเข้าใจ

เป้าหมาย ตั้งค่า GitHub CLI แล้วส่ง repo ในเครื่องขึ้น GitHub เป็นครั้งแรก

GitHub คือเว็บที่เก็บ repo Git ไว้บนเซิร์ฟเวอร์ ใช้แชร์โค้ดกับทีม และเป็นที่ที่ CI (บท 21) จะรัน ส่วน GitHub CLI (gh) คือโปรแกรมที่ให้สั่งงาน GitHub จาก terminal ได้ เช่น สร้าง repo หรือเปิด Pull Request โดยไม่ต้องคลิกบนเว็บ

ขั้นที่ 1: สมัครบัญชี GitHub

ถ้ายังไม่มีบัญชี ให้สมัครที่ github.com/signup แล้วยืนยันอีเมลให้เรียบร้อย ถ้ามีแล้วข้ามขั้นนี้ได้

ขั้นที่ 2: ติดตั้ง GitHub CLI

  1. เปิด PowerShell แล้วรันคำสั่งแรกข้างล่าง (ใช้ winget ที่มากับ Windows 10/11) หรือดาวน์โหลดตัวติดตั้งจาก cli.github.com
  2. ปิด PowerShell แล้วเปิดใหม่ จากนั้นรัน gh --version ต้องเห็นเลขเวอร์ชัน
PowerShell
winget install --id GitHub.cli
gh --version

ขั้นที่ 3: login ครั้งเดียว

รัน gh auth login แล้วตอบคำถามตามนี้ (ใช้ลูกศรขึ้นลงเลือก แล้วกด Enter)

  1. Where do you use GitHub? → GitHub.com
  2. What is your preferred protocol for Git operations? → HTTPS
  3. Authenticate Git with your GitHub credentials? → Yes
  4. How would you like to authenticate GitHub CLI? → Login with a web browser
  5. terminal จะแสดงรหัส 8 ตัว (one-time code) จดไว้ แล้วกด Enter เบราว์เซอร์จะเปิดหน้า GitHub ให้ใส่รหัสนั้น แล้วกด Authorize

เช็ก: รัน gh auth status ต้องเห็นข้อความว่า Logged in to github.com พร้อมชื่อบัญชีของคุณ

PowerShell
gh auth login
gh auth status

ขั้นที่ 4: สร้าง repo บน GitHub แล้ว push

เข้าไปในโฟลเดอร์ repo จากบท 15 แล้วรันคำสั่งข้างล่าง คำสั่ง gh repo create จะสร้าง repo ชื่อเดียวกันบน GitHub ตั้งชื่อ remote ว่า origin แล้ว push commit ทั้งหมดขึ้นไปในขั้นตอนเดียว

terminal
cd ~/xiao-embedded-cpp
gh repo create xiao-embedded-cpp --public --source=. --remote=origin --push
gh repo view --web          # เปิดหน้า repo ในเบราว์เซอร์

เช็ก: หน้า repo บน GitHub ต้องเห็นโฟลเดอร์ firmware/ และไฟล์ .gitignore ส่วนแท็บ Commits ต้องเห็น commit จากบท 15–16 ตั้งแต่นี้ไป ทุกครั้งที่ commit ในเครื่องแล้ว ให้รัน git push เพื่อส่งขึ้น GitHub

เช็กความเข้าใจ

fetch กับ pull ต่างกันอย่างไร?

fetch ดึงข้อมูล remote มาเก็บไว้ (origin/main) แต่ยังไม่แตะ branch ของเรา pull = fetch + merge (หรือ rebase) เข้ามา

origin คืออะไร?

ชื่อเล่นของ URL ของ repo บนเซิร์ฟเวอร์ ตั้งชื่ออื่นได้ แต่ origin เป็นธรรมเนียมสำหรับ remote หลัก ดูได้ด้วย git remote -v
