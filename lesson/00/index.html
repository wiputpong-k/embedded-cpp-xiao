เป้าหมาย IDE คอมไพล์และแฟลชบอร์ดได้ รู้ว่า LED บนบอร์ดเป็น active-LOW

บทนี้เป็นบทติดตั้ง จึงใช้เวลานานกว่าบทอื่น ทำตามทีละขั้นจากบนลงล่าง ท้ายแต่ละขั้นมีวิธีเช็กว่าทำสำเร็จแล้ว ตัวอย่างเขียนสำหรับ Windows ถ้าใช้ macOS ให้ดูหมายเหตุในขั้นนั้น

ขั้นที่ 1: ติดตั้ง Arduino IDE 2

Arduino IDE คือโปรแกรมที่ใช้เขียนโค้ด compile และอัปโหลดลงบอร์ด

  1. เปิดหน้า arduino.cc/en/software
  2. ในหัวข้อ Arduino IDE 2 เลือกตัวติดตั้งของ Windows (Win 10 and newer) ถ้าหน้าเว็บขอรับบริจาค กด Just Download ได้เลย
  3. เปิดไฟล์ที่ดาวน์โหลดมา กด Next ตามค่าเริ่มต้นจนจบ ถ้า Windows ถามว่าจะติดตั้ง driver ไหม ให้กด Install
  4. เปิด Arduino IDE ครั้งแรก โปรแกรมอาจดาวน์โหลดส่วนประกอบเพิ่มสักครู่ ถ้า firewall ถามสิทธิ์ ให้กด Allow

เช็ก: เปิดโปรแกรมแล้วเห็นหน้าต่างที่มีโค้ด void setup() และ void loop() ว่าง ๆ

ขั้นที่ 2: เพิ่มแหล่งดาวน์โหลดบอร์ด Seeed

Arduino IDE ไม่มีบอร์ด XIAO มาให้ตั้งแต่แรก ต้องบอก IDE ก่อนว่าจะดาวน์โหลดข้อมูลบอร์ดของ Seeed จากที่ไหน

  1. ใน Arduino IDE กดเมนู File → Preferences… (macOS: Arduino IDE → Settings…) จะมีหน้าต่าง Preferences เปิดขึ้นมา
  2. หาช่อง Additional boards manager URLs ซึ่งอยู่ใกล้ด้านล่างของหน้าต่าง
  3. กดปุ่มคัดลอกที่ URL ข้างล่าง แล้ววางในช่องนั้น ถ้าในช่องมี URL อื่นอยู่แล้ว ให้กดไอคอนทางขวาของช่อง แล้ววางเป็นบรรทัดใหม่
  4. กด OK เพื่อปิดหน้าต่าง
Additional boards manager URLs
https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json

ขั้นที่ 3: ติดตั้ง core ของบอร์ด

core คือชุดไฟล์ที่ทำให้ IDE รู้จักบอร์ด รวมถึง compiler สำหรับชิป nRF52840

  1. เปิด Boards Manager โดยกดไอคอนรูปบอร์ดที่แถบซ้ายมือ (ไอคอนที่ 2 จากบน) หรือเมนู Tools → Board → Boards Manager…
  2. พิมพ์ seeed nrf52 ในช่องค้นหา จะเจอ 2 รายการ ให้เลือก Seeed nRF52 Boards ไม่ใช่ Seeed nRF52 mbed-enabled Boards
  3. กด Install แล้วรอ อาจใช้เวลาหลายนาทีเพราะต้องดาวน์โหลด compiler ด้วย ถ้ามีหน้าต่างถามเรื่อง driver ให้กด Install หรือ Yes

เลือก core แบบ non-mbed เพราะ build เร็วกว่าและใช้ BLE library ของ Adafruit ได้ เช็ก: รายการ Seeed nRF52 Boards ขึ้นคำว่า INSTALLED

ขั้นที่ 4: ต่อบอร์ด แล้วเลือกบอร์ดกับพอร์ต

  1. เสียบบอร์ดเข้าคอมด้วยสาย USB-C ที่ส่งข้อมูลได้ (สายที่มากับที่ชาร์จบางเส้นชาร์จได้อย่างเดียว)
  2. กดเมนู Tools → Board → Seeed nRF52 Boards → Seeed XIAO nRF52840 Sense
  3. กดเมนู Tools → Port แล้วเลือกพอร์ตของบอร์ด (Windows เป็น COM ตามด้วยตัวเลข เช่น COM5 macOS เป็น /dev/cu.usbmodem…)

เช็ก: ถ้าไม่รู้ว่าพอร์ตไหนคือบอร์ด ให้ถอดสายแล้วเปิดเมนู Port ดูอีกครั้ง พอร์ตที่หายไปคือบอร์ด ถ้าไม่มีพอร์ตขึ้นเลย ให้ลองเปลี่ยนสาย USB

Hands-on: Blink แรก

  1. กดเมนู File → New Sketch จะได้หน้าต่างใหม่ที่มีโค้ดตั้งต้น
  2. ลบโค้ดเดิมทั้งหมด แล้วกดปุ่ม คัดลอก ที่มุมขวาบนของโค้ดข้างล่าง มาวางแทน
  3. กดเมนู File → Save As… แล้วตั้งชื่อ blink
  4. กดปุ่ม Verify (เครื่องหมายถูกที่มุมซ้ายบน) เพื่อ compile ครั้งแรกอาจนานเป็นนาที รอจนเห็น Done compiling ที่ด้านล่าง
  5. กดปุ่ม Upload (ลูกศรขวาถัดจาก Verify) แล้วรอจนเห็น Done uploading
blink.ino
// LED บนบอร์ดต่อขั้วบวกไว้ที่ 3V3 จึงติดเมื่อเขียน LOW
void setup() {
  pinMode(LED_RED, OUTPUT);
  digitalWrite(LED_RED, HIGH);   // ดับ
}

void loop() {
  digitalWrite(LED_RED, LOW);    // ติด
  delay(200);
  digitalWrite(LED_RED, HIGH);   // ดับ
  delay(800);
}

ผลที่ควรเห็น: LED สีแดงบนบอร์ดกระพริบ ติด 0.2 วินาที ดับ 0.8 วินาที วนไปเรื่อย ๆ

ถ้าอัปโหลดไม่ผ่าน: กดปุ่ม reset บนบอร์ด (ปุ่มเล็กข้างช่อง USB) 2 ครั้งเร็ว ๆ บอร์ดจะเข้าโหมด bootloader (Windows อาจเห็นไดรฟ์ใหม่ขึ้นมา) จากนั้นเปิด Tools → Port เลือกพอร์ตใหม่ เพราะเลขพอร์ตอาจเปลี่ยน แล้วกด Upload อีกครั้ง

ลองต่อ

  1. เปลี่ยน LED_RED เป็น LED_GREEN หรือ LED_BLUE ให้ครบทั้ง 3 จุด แล้ว Upload ใหม่ สีของ LED ต้องเปลี่ยนตาม
  2. เปิด File → Preferences… ติ๊กช่อง Show verbose output during: compile กด OK แล้วกด Verify อีกครั้ง หน้าต่าง Output ด้านล่างจะแสดงคำสั่ง compiler ที่ IDE เรียกจริง บท 01 จะอธิบายว่าแต่ละคำสั่งทำอะไร

เช็กความเข้าใจ

ทำไม LED_RED ติดตอนเขียน LOW?

LED ต่อแบบ active-LOW: ขั้วบวกอยู่ที่ 3V3 ขา GPIO ทำหน้าที่ sink กระแส เมื่อขาเป็น LOW จึงมีกระแสไหล

ทำไมต้องใช้ core non-mbed ในคอร์สนี้?

build เร็วกว่า ใช้ Bluefruit BLE ได้ และ compile ใน CI ได้ง่าย ทั้งสอง core เขียน C++ ได้เหมือนกัน
