เป้าหมาย ต่อปุ่มกด และเขียน debounce แบบ non-blocking เป็น class ที่ไม่พึ่ง Arduino (จะ test บน PC ในบท 19)

ต่อวงจร

ปุ่มกด tactile มี 4 ขา ขาที่อยู่ฝั่งเดียวกันเป็นคู่ที่ต่อกันอยู่แล้วข้างใน ถ้าวางผิดทิศ ปุ่มจะดูเหมือนกดค้างตลอดเวลา วิธีที่ปลอดภัยที่สุดคือใช้ขาที่อยู่ ทแยงมุม กัน เพราะจะเป็นคนละคู่เสมอ

  1. ถอดสาย USB ออกก่อน
  2. เสียบปุ่มคร่อมร่องกลางของ breadboard
  3. ต่อสายจากขาหนึ่งของปุ่มไปที่ขา D1
  4. ต่อขาที่อยู่ทแยงมุมกับขานั้นไปที่ GND

วงจรนี้ไม่ต้องใช้ R ภายนอก เพราะโค้ดจะเปิด INPUT_PULLUP คือ R ภายในชิปที่ดึงขา D1 ขึ้นไปที่ 3.3 V ตอนปล่อยปุ่มขาจึงเป็น HIGH และตอนกดปุ่ม ขาถูกต่อลง GND จึงเป็น LOW

ทำไมต้อง debounce

หน้าสัมผัสโลหะในปุ่มจะเด้งกระทบกันหลายครั้งในช่วง 1–5 ms แรกของการกด ถ้าโค้ดอ่านขาตรง ๆ กดครั้งเดียวอาจนับได้หลายครั้ง Debouncer แก้ปัญหานี้โดยยืนยันสถานะใหม่ก็ต่อเมื่อสัญญาณนิ่งต่อเนื่องครบเวลาที่กำหนด (ค่าเริ่มต้น 20 ms)

Hands-on

  1. สร้าง sketch ใหม่ (File → New Sketch) แล้วบันทึกชื่อ button_count
  2. สร้างไฟล์ src/Debouncer.h แบบเดียวกับบท 05 (Sketch → Show Sketch Folder → สร้างโฟลเดอร์ src → สร้างไฟล์ Debouncer.h) แล้ววางโค้ดชุดแรกข้างล่าง
  3. วางโค้ดชุดที่สองลงใน button_count.ino แล้วกด Upload
  4. เปิด Tools → Serial Monitor แล้วตั้งค่าความเร็วที่มุมขวาของหน้าต่าง Serial Monitor เป็น 115200 baud ให้ตรงกับ Serial.begin(115200) ในโค้ด
  5. กดปุ่มทีละครั้ง ตัวเลข presses ต้องเพิ่มทีละ 1
src/Debouncer.h
#pragma once
#include <stdint.h>

// Pure logic: ไม่เรียก Arduino API เลย จึง test บน PC ได้
class Debouncer {
public:
  enum class Event : uint8_t { None, Pressed, Released };

  explicit Debouncer(uint32_t stableMs = 20) : stableMs_(stableMs) {}

  // raw: true = กดอยู่ (แปลง active-LOW มาแล้ว), nowMs: เวลาปัจจุบัน
  Event update(bool raw, uint32_t nowMs) {
    if (raw != lastRaw_) {  // ยังเด้งอยู่ → เริ่มจับเวลาใหม่
      lastRaw_ = raw;
      changedAt_ = nowMs;
      return Event::None;
    }
    if (raw != stable_ && (nowMs - changedAt_) >= stableMs_) {
      stable_ = raw;
      return stable_ ? Event::Pressed : Event::Released;
    }
    return Event::None;
  }

  bool isPressed() const { return stable_; }

private:
  uint32_t stableMs_;
  uint32_t changedAt_ = 0;
  bool lastRaw_ = false;
  bool stable_ = false;
};
button_count.ino
#include <Adafruit_TinyUSB.h>   // เปิด USB และ Serial (core นี้ต้องมี)
#include "src/Debouncer.h"

constexpr uint8_t kButtonPin = D1;

Debouncer button;        // stableMs = 20 (ค่าเริ่มต้น)
uint32_t presses = 0;

void setup() {
  Serial.begin(115200);
  pinMode(kButtonPin, INPUT_PULLUP);
}

void loop() {
  bool pressed = (digitalRead(kButtonPin) == LOW);   // active-LOW → true = กด
  if (button.update(pressed, millis()) == Debouncer::Event::Pressed) {
    presses++;
    Serial.print("presses = ");
    Serial.println(presses);
  }
}

Debouncer ทำงานอย่างไร

  • update() ถูกเรียกทุกรอบ loop พร้อมค่าที่อ่านได้ (raw) และเวลาปัจจุบัน (nowMs) ไม่มี delay() เลย loop จึงทำงานอื่นต่อได้
  • ถ้า raw ต่างจากรอบที่แล้ว แปลว่ายังเด้งอยู่ จึงจำเวลาไว้ใน changedAt_ แล้วเริ่มนับใหม่
  • ถ้า raw นิ่งมานานครบ stableMs_ และต่างจากสถานะที่ยืนยันแล้ว (stable_) จึงเปลี่ยนสถานะ แล้วคืน Event::Pressed หรือ Event::Released ครั้งเดียว
  • class นี้ไม่เรียก millis() หรือ digitalRead() เอง ผู้เรียกเป็นคนส่งค่าเข้ามา จึงนำไป test บน PC ได้ในบท 19

ลองเปลี่ยนบรรทัด Debouncer button; เป็น Debouncer button(0); (ไม่รอให้นิ่งเลย) แล้ว Upload ใหม่ กดปุ่มดูว่าบางครั้งตัวเลขกระโดดเพิ่มทีละหลายค่า นั่นคือ bounce ที่ Debouncer กรองออก จากนั้นเปลี่ยนกลับ

เช็กความเข้าใจ

ทำไม nowMs - changedAt_ ยังถูกต้องแม้ millis() overflow (ราว 49.7 วัน)?

การลบ unsigned 32-bit เป็น modulo 2³² ผลต่างจึงถูกเสมอตราบใดที่ช่วงเวลาไม่เกิน 49.7 วัน ห้ามเขียนแบบ now > changedAt_ + stableMs_ เพราะพังตอน overflow

ทำไมไม่ใช้ delay(20) หลังอ่านปุ่มแทน?

delay() หยุดทั้งโปรแกรม ระหว่างนั้นอ่านเซนเซอร์หรือกระพริบ LED ไม่ได้ และยังพลาดการกดสั้น ๆ ได้ Debouncer แบบนี้ใช้เวลาแค่ไม่กี่ไมโครวินาทีต่อรอบ
