State machine

25 min · Hardware: Button on D1

In this lesson
  1. Hands-on
  2. Check your understanding

Goal Use the debounced button to switch LED blink modes with a non-blocking state machine

A state machine keeps the program in exactly one state at a time and changes state only when an event happens. This lesson has 3 states: Off, Slow (blink every 500 ms) and Fast (every 100 ms). The only event is Event::Pressed from the Debouncer in the previous lesson.

An enum class Mode (lesson 03) holds the state, and the transition rules live in one function, next(), so when you add a mode you know exactly where to change things.

Hands-on

  1. Create a new sketch named button_modes.
  2. Copy the src folder from the button_count sketch into the new sketch's folder (use Sketch → Show Sketch Folder to open both folders).
  3. Paste the code below into button_modes.ino and click Upload.
  4. Press the button: the green LED should go off → slow blink → fast blink → off, and around again.
button_modes.ino
#include <Adafruit_TinyUSB.h>   // enables USB and Serial (required by this core)
#include "src/Debouncer.h"

constexpr uint8_t kButtonPin = D1;
enum class Mode : uint8_t { Off, Slow, Fast };

Debouncer button;
Mode mode = Mode::Off;
uint32_t lastToggle = 0;
bool ledLit = false;

Mode next(Mode m) {
  switch (m) {
    case Mode::Off:  return Mode::Slow;
    case Mode::Slow: return Mode::Fast;
    case Mode::Fast: return Mode::Off;
  }
  return Mode::Off;
}

uint32_t periodMs(Mode m) { return m == Mode::Slow ? 500 : 100; }

void setup() {
  pinMode(kButtonPin, INPUT_PULLUP);
  pinMode(LED_GREEN, OUTPUT);
  digitalWrite(LED_GREEN, HIGH);
}

void loop() {
  uint32_t now = millis();
  bool pressed = (digitalRead(kButtonPin) == LOW);
  if (button.update(pressed, now) == Debouncer::Event::Pressed) {
    mode = next(mode);
  }
  if (mode == Mode::Off) {
    digitalWrite(LED_GREEN, HIGH);
  } else if (now - lastToggle >= periodMs(mode)) {
    lastToggle = now;
    ledLit = !ledLit;
    digitalWrite(LED_GREEN, ledLit ? LOW : HIGH);
  }
}

Notice that the blinking uses now - lastToggle >= periodMs(mode) instead of delay(). loop keeps spinning fast, so the button responds immediately even in Slow mode.

Check your understanding

Why is there another return Mode::Off after the switch?

Some compilers warn "control reaches end of non-void function" even when every case is covered. It is there for safety and a warning-free build.

What would you change to add an "always on" mode?

Add a name to enum class Mode, add cases in next() to enter and leave the new mode, and add a branch in loop that holds the pin LOW. Nothing else changes.
