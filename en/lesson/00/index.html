Module 0 · Setup

Install the tools + first Blink

Goal The IDE compiles and flashes the board, and you know the on-board LED is active-LOW

This is the setup lesson, so it takes longer than the others. Work through the steps from top to bottom; each step ends with a way to check that it worked. The instructions are for Windows; macOS notes are given where they differ.

Step 1: Install Arduino IDE 2

Arduino IDE is the program you use to write code, compile it and upload it to the board.

  1. Open arduino.cc/en/software
  2. Under Arduino IDE 2, pick the Windows installer (Win 10 and newer). If the page asks for a donation, you can click Just Download.
  3. Run the downloaded file and click Next through the defaults. If Windows asks whether to install a driver, click Install.
  4. Start Arduino IDE. The first launch may download extra components; if the firewall asks for permission, click Allow.

Check: the program opens a window with empty void setup() and void loop() functions.

Step 2: Add the Seeed board source

Arduino IDE does not include the XIAO board out of the box. First you tell the IDE where to download Seeed's board package from.

  1. In Arduino IDE, open File → Preferences… (macOS: Arduino IDE → Settings…). The Preferences window opens.
  2. Find the Additional boards manager URLs field near the bottom of the window.
  3. Copy the URL below with its copy button and paste it into that field. If the field already has other URLs, click the icon on the right of the field and paste it on a new line.
  4. Click OK to close the window.
Additional boards manager URLs
https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json

Step 3: Install the board core

A core is the set of files that teaches the IDE about a board, including the compiler for the nRF52840 chip.

  1. Open Boards Manager: click the board icon in the left sidebar (second icon from the top), or use Tools → Board → Boards Manager…
  2. Type seeed nrf52 in the search box. Two entries appear; pick Seeed nRF52 Boards, not Seeed nRF52 mbed-enabled Boards.
  3. Click Install and wait. It can take several minutes because it also downloads the compiler. If a window asks about a driver, click Install or Yes.

We use the non-mbed core because it builds faster and works with Adafruit's BLE library. Check: the Seeed nRF52 Boards entry shows INSTALLED.

Step 4: Connect the board and pick the board and port

  1. Plug the board into your computer with a USB-C cable that carries data (some charger cables only carry power).
  2. Open Tools → Board → Seeed nRF52 Boards → Seeed XIAO nRF52840 Sense
  3. Open Tools → Port and pick the board's port (on Windows, COM plus a number, e.g. COM5; on macOS, /dev/cu.usbmodem…).

Check: if you are not sure which port is the board, unplug the cable and open the Port menu again; the port that disappeared is the board. If no port shows up at all, try another USB cable.

For the detailed pin map, see the official front pinout and back pinout on the Seeed Studio Wiki (large files, about 2.6 MB). In the ARDUINO NAME column the numbers read "Mbed core / Non-Mbed core"; this course uses the non-mbed core, so use the second number.

Hands-on: your first Blink

  1. Open File → New Sketch. A new window opens with starter code.
  2. Delete all of that code, click the Copy button at the top right of the code below, and paste it in.
  3. Open File → Save As… and name it blink. Save it in the normal sketchbook folder (Documents\Arduino) or any other folder whose full path has no spaces.
  4. Click Verify (the check mark at the top left) to compile. The first compile can take a minute; wait for Done compiling at the bottom.
  5. Click Upload (the right arrow next to Verify) and wait for Done uploading.
blink.ino
// The on-board LED anode is tied to 3V3, so it lights when you write LOW
void setup() {
  pinMode(LED_RED, OUTPUT);
  digitalWrite(LED_RED, HIGH);   // off
}

void loop() {
  digitalWrite(LED_RED, LOW);    // on
  delay(200);
  digitalWrite(LED_RED, HIGH);   // off
  delay(800);
}

What you should see: the red LED on the board blinks, on for 0.2 s and off for 0.8 s, over and over.

If the upload fails: double-press the reset button on the board (the tiny button next to the USB port) quickly. The board enters bootloader mode (Windows may show a new drive). Then open Tools → Port and pick the port again, because its number may change, and click Upload again.

If Verify fails with arm-none-eabi-g++: error: … No such file or directory followed by pieces of your folder name, the sketch path contains spaces, e.g. D:\My Projects\blink. The Seeed nRF52 core passes the path to the compiler without quotes, so it gets split at each space. Fix it with File → Save As… into a folder without spaces, such as Documents\Arduino, or rename the folders to use _ instead of spaces.

Try next

  1. Change LED_RED to LED_GREEN or LED_BLUE in all three places and upload again. The LED color should change.
  2. Open File → Preferences…, tick Show verbose output during: compile, click OK and click Verify again. The Output panel at the bottom shows the compiler commands the IDE actually runs; lesson 01 explains what each one does.

Check your understanding

Why does LED_RED light when you write LOW?

The LED is active-LOW: its anode sits at 3V3 and the GPIO pin sinks the current, so current flows when the pin is LOW.

Why use the non-mbed core in this course?

It builds faster, supports Bluefruit BLE and is easy to compile in CI. Both cores run the same C++.
